KAMPUSLOKKI
This was a group project for Embedded Systems course. The idea was to create radio controllable ornithopter which has motor throttle that controls the wing flapping frequency and servo throttle that controls the tail. We had ~Arduino Nicla Sense ME~ for the controlling and basic radio controller attached to it with all the properties needed for controlling the flight path of the ornithopter.

My task for this project was to program the Nicla to control the wing-flapping and tail. Also, I did some of the solding. Other tasks for this project were to build the body, tail and wings of the ornithopter. Those were assigned for other group members.
